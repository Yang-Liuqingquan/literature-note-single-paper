# 文献笔记生成器（单篇版）

在 Obsidian 里从 Zotero 条目一键生成单篇文献的阅读笔记骨架：六节固定结构、每节自带「节功能描述」与「节编辑指南」、文献信息与 APA 引用自动填好，剩下的正文留给你（或大语言模型）慢慢写。新建笔记时自动给 Zotero 条目打标签，删掉最后一篇相关笔记时再把标签撤掉。

插件界面为中文，只支持桌面版 Obsidian。

## 它替你省掉什么

- 不用再手动抄标题、作者、年份、文献类型、摘要和 APA 引用；
- 不用每次重搭那套六节骨架（含导语与缺省占位符）；
- 不用手动维护「这篇笔记对应 Zotero 里哪个条目」——`.md` 里的 Zotero 链接就是索引，插件自己认；
- 不用在 Zotero 与 Obsidian 之间来回切换选条目：装了 Better BibTeX 后，直接从 Zotero 的原生选择窗里挑。

## 依赖清单

**必需**

| 依赖 | 说明 |
|---|---|
| Obsidian 1.4 及以上，桌面版 | 插件用到 Node 的 `http` 与 `fs`，移动端跑不了 |
| Zotero 7（桌面版，与 Obsidian 同一台机器） | 需在「设置 → 高级」勾选 **允许本机其他应用与 Zotero 通信**；插件只访问 `127.0.0.1:23119`，不联网 |

**可选（装了好用，不装也能用）**

| 依赖 | 作用 | 不装会怎样 |
|---|---|---|
| Better BibTeX for Zotero | 提供 `/better-bibtex/cayw` 接口，选条目时弹 Zotero 原生窗口 | 退回插件内置选择器，多一步手动搜索 |
| Zotero 里的 PDF 附件 | 笔记里「原文 PDF」链接指向它 | 该行写「数据缺失」 |
| 自定义模板 | 放在 `templates/文献笔记模板.md` | 用内置模板，功能不变 |

**不需要**——这一节专门用来消除误会：

| 常被当成依赖的 | 实情 |
|---|---|
| Templater | **不需要**。本插件只把 `{{title}}` 这类占位符当纯文本替换，模板里没有 `<% %>` 语法，也不调用 Templater 的任何接口 |
| Dataview | **不需要**。生成的笔记里没有 dataview 查询块 |
| Zotero Integration（obsidian-zotero-desktop-connector） | **不需要**。插件自己走 Zotero 本地 HTTP API，与这个插件互不依赖 |
| Pandoc / 其他导出类插件 | **不需要** |

想自己核实：源码里没有任何对其他 Obsidian 插件的能力性调用（`app.plugins` 只在诊断面板里读一次「当前启用了哪些」，用于展示），模板文件里 `<%` 与 `dataview` 的出现次数都是 0。

一句话：**只装 Obsidian + Zotero 就能跑，Better BibTeX 只是体验加成。**

## 安装

**方式一：手动安装（当前推荐）**

1. 下载本仓库的 `main.js`、`manifest.json`、`styles.css`；
2. 放到 `<你的仓库>/.obsidian/plugins/literature-note-single/`；
3. 重启 Obsidian，在「设置 → 第三方插件」里启用「文献笔记生成器（单篇版）」。

**方式二：BRAT**

在 BRAT 里添加 `YOUR-NAME/literature-note-single`。发布过 Release 之后这种方式才可用。

## 第一次使用与设置向导

插件启用后第一次加载会**自动弹出一次向导**；此后不再自动弹，但随时可以用命令 **打开设置向导**（或设置页顶部的同名按钮）重新打开。向导逐项自检：

1. **Zotero 本地 API** —— 没连上就按提示去 Zotero 里打开本机通信开关；
2. **Better BibTeX 的 CAYW 接口** —— 没装会标黄，插件仍可用，只是改用内置选择器；
3. **模板文件** —— 不存在也没关系，建笔记时用内置模板；想让模板可编辑，点「安装内置模板」；
4. **Zotero 写入授权** —— 首次加标签时 Zotero 会弹窗问权限，选 **Always Allow** 可长期免弹窗；
5. **标签联动** —— 显示当前标签与自动加/删开关。

向导里还能顺手设好「默认目录」。同一个面板也可以从命令 **检查运行环境** 打开，出错时点「复制诊断信息」把整段贴进 issue。

## 命令

| 命令 | 作用 |
|---|---|
| 为Zotero条目创建文献笔记 | 选条目 → 选目标目录 → 生成笔记并打开 |
| 检查运行环境 | 打开诊断面板，逐项检查依赖 |
| 打开设置向导 | 随时打开向导，复查环境与顺手设默认目录（首次加载会自动弹一次） |
| 同步待处理的 Zotero 标签 | Zotero 没开或当时没授权而排队的加/删标签，一次性补完 |
| 为当前笔记补打 Zotero 标签 | 老笔记没有标签时，手动补一次 |

侧边栏也有一个笔记本图标，效果同第一条命令。

## 笔记长什么样

```
# 文献信息            ← 标题/作者/发表时间/文献类型/摘要/APA 引用/Zotero 链接/URL/PDF
# 直觉感悟与扩展讨论    ← 【待手动填充】
# 个别要点详述         ← 【待手动填充】
# 全文详细解析         ← 【待大语言模型生成】
# 索引速查项           ← 七个小节，均为【待大语言模型生成】
# 附：如何更新本模板    ← 模板维护说明
```

- 文献信息缺失的字段一律写「数据缺失」；
- 文件名默认「第一作者姓 + 四位年份 + 标题前三词」，如 `mallory2026Formatsofrepresentation.md`，中文标题取前 8 个字；
- 同名文件已存在时**不覆盖**，只打开已有文件；
- 目录可以现场输入一个不存在的路径（可多级），回车即新建。

## 设置项

| 设置 | 默认值 | 说明 |
|---|---|---|
| Zotero 本地 API 地址 | `http://127.0.0.1:23119/api/users/0` | 改过端口才需要动 |
| 模板文件路径 | `templates/文献笔记模板.md` | 缺失时用内置模板 |
| 文件名标题词数 | `3` | 中文标题按字数截取，不受此项影响 |
| 默认目录 | 空（每次询问） | 设了就默认停在该目录，仍可临时改 |
| 用 Zotero 原生选择窗 | 关 | 开启后加 `&selected=true`，只返回 Zotero 里选中的条目 |
| 标签 | `#带obs笔记` | 加在 Zotero 条目上 |
| 新建笔记后自动加标签 | 开 | 关掉后只建笔记，不碰 Zotero |
| 删除笔记后自动移除标签 | 开 | 仅在无其他笔记引用该条目时移除 |
| 调试日志 | 关 | 排查「点了没反应」时打开，写插件目录下 `last-run.log` |

## 模板

模板是可选的。不装模板就用内置的那份；想改结构就点设置里的「安装内置模板」，或手动把 [`文献笔记模板.md`](文献笔记模板.md) 放进 `templates/`。模板支持这些占位符：

`{{title}}` `{{authors}}` `{{date}}` `{{itemType}}` `{{abstract}}` `{{citation}}` `{{zoteroLink}}` `{{url}}` `{{pdfLink}}`

写进行内代码或围栏代码块里的占位符会被原样保留，方便你在模板里写说明。改完保存即生效，不用重启 Obsidian。

## 排错

| 现象 | 处理 |
|---|---|
| 提示连不上 Zotero | 确认 Zotero 在运行；「设置 → 高级」勾选允许本机通信；别只开 Zotero 的「快速启动」而没开主程序 |
| 选条目时没有 Zotero 弹窗 | 装并启用 Better BibTeX；或看设置里「用 Zotero 原生选择窗」是否被关掉，此时会改用内置选择器 |
| 加标签时反复弹授权 | 弹窗里选 **Always Allow**；选 Allow 只对当次有效 |
| 标签没加上 | 用命令「同步待处理的 Zotero 标签」，或看诊断里的「Zotero 写入授权」 |
| 点了命令没反应 | 设置里打开「调试日志」，复现一次，把 `last-run.log` 发来 |
| 笔记里的 PDF 链接打不开 | 条目下没有 PDF 附件，或附件不在 Zotero 管理的目录里；该项会写「数据缺失」 |

## 数据与隐私

- 所有请求都发往本机 `127.0.0.1`，插件不收集、不上传任何数据；
- Zotero 写入凭据（API key 与 server id）保存在本插件的 `data.json` 里，可在设置里随时解除；
- 调试日志默认关闭，开启后也只写到本机插件目录。

## 已知限制

- 只处理单篇文献。整本书的「总论 + 分章计划」流程在旧版里，本版已移除；`book` 类型条目也按单篇处理。
- 移动端不可用（依赖本地 HTTP 与 Node 文件 API）。
- 标签联动依赖 Zotero 7 的本地写入授权接口，Zotero 6 不支持。
